# Mini-sistema-de-recomenda-o-de-vinhos.
O sistema funciona da seguinte forma, você escolhe um tipo de carne e o sistema recomenda um tipo de vinho. 

## Funcionalidades
- Exibição de menu de carnes
- Escolha interativa via terminal
- Sugestão de vinhos conforme o tipo de carne
- Estrutura condicional usando `if` e `match case`

## Tecnologias
- Python 3.10+

## Objetivo
Projeto criado com fins educacionais para praticar lógica de programação, condicionais e interação com o usuário.
